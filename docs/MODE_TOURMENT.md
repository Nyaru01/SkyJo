# 🌪️ Mode Tourment - Règles du Jeu

Bienvenue dans le **Mode Tourment**, la variante la plus extrême et stratégique de Vesper ! 
Ce mode ajoute **24 cartes spéciales** au deck original, introduisant de nouvelles mécaniques impitoyables et des retournements de situation spectaculaires.

---

## 🃏 Les Nouvelles Cartes Spéciales

### 1. La Carte (-10) 🌟
* **Apparence** : Violette
* **Valeur** : **-10 points**
* **Quantité** : 6 exemplaires
* **Description** : C'est la carte la plus puissante du jeu ! Elle réduit considérablement votre score.

### 2. Le Crâne Maudit (20) 💀
* **Apparence** : Rouge Sanguine
* **Valeur** : **20 points**
* **Quantité** : 6 exemplaires
* **Malédiction** : 
  * Si vous la piochez (dans la pioche), vous êtes **OBLIGÉ** de la placer dans votre jeu.
  * Une fois posée, elle est **VERROUILLÉE** pendant **3 rounds**.
  * **Verrouillage** : Impossible de la défausser, de l'échanger ou de la remplacer tant que le cadenas est actif.

### 3. L'Échange (S) 🔄
* **Apparence** : Bleu Nuit avec flèches
* **Valeur** : Action Spéciale
* **Quantité** : 4 exemplaires
* **Effet** : 
  * Cette carte ne se place pas dans votre jeu. 
  * Elle vous permet d'**échanger** immédiatement l'une de vos cartes (visible ou cachée) avec celle d'un autre joueur.
  * *Stratégie* : Utilisez-la pour voler un -10 ou refiler votre Crâne Maudit !
* **Règle Spéciale** : Impossible de la récupérer depuis la défausse.

### 4. Le Nettoyage (C) ✨
* **Apparence** : Indigo avec une Étoile
* **Valeur** : **0 point** (intrinsèque)
* **Quantité** : 4 exemplaires
* **Effet (Joker)** : 
  * Elle agit comme un **Joker de complétion** pour valider une colonne.
  * **Alignement** :
    * 2 cartes identiques + 1 Étoile = Colonne validée (0 points).
    * 1 carte + 2 Étoiles = Colonne validée (0 points).
    * 3 Étoiles = Colonne validée (0 points).

### 5. La Carte Mystère (?) 📦
* **Apparence** : Dorée avec un coffre
* **Valeur en jeu** : **0 point** (compte comme un 0 pour les colonnes)
* **Valeur finale** : **-15** ou **+15 points**
* **Quantité** : 4 exemplaires
* **Effet** :
  * Sa véritable valeur n'est révélée qu'à la **toute fin de la partie**.
  * C'est un pari risqué : cela peut être un trésor (Bonus -15) ou un piège (Malus +15).
  * *Astuce* : Utilisez-la comme un 0 pour éliminer une colonne si vous ne voulez pas prendre le risque du tirage final.

## 📜 Règles Additionnelles

### 🚫 Verrouillage
Une carte verrouillée (comme le Crâne Maudit) ne peut subir aucune action :
* Elle ne peut pas être remplacée par une carte piochée.
* Elle ne peut pas être ciblée par une carte "Échange".
* Elle ne peut pas être retournée si elle est encore face cachée (cas rares).
* Le verrou saute automatiquement après 3 tours de table.

### 👁️ Vision et Mémoire
* **Appui Long sur la Défausse** : À tout moment, vous pouvez maintenir l'appui sur la pile de défausse pour voir les **3 dernières cartes jouées**. Indispensable pour suivre les cartes Échange ou les -10 disparus !

### 🏁 Fin de Partie
Les règles de fin de partie restent les mêmes que le jeu classique :
* La manche s'arrête lorsqu'un joueur a retourné toutes ses cartes.
* Les autres joueurs ont un dernier tour.
* **Attention** : Les Cartes Mystères sont résolues après le dernier tour. Le score affiché pendant la partie peut donc changer brutalement au moment du décompte final !
